# OC Skills

这个仓库用于管理原创角色（OC）设计与插画生成技能。

## 技能

- `skills/oc-character-designer-skill`：OC 角色设定、Root Canon、阶段化问答、文件持久化与横向设定集模板。
- `skills/oc-illustration-director-skill`：消费上游 Canon 交接包，完成插画导演、构图、镜头、光影、风格与连续性管理。

## 当前版本

- OC Character Designer: `3.1.1`
- OC Illustration Director: `2.0.1`
- Character Bible Templates: `1.1.0`

两个技能通过只读 handoff 协议衔接：人体与五官 Root Canon 由上游管理，下游仅选择强参考与批准变体，并负责插画表现层。
