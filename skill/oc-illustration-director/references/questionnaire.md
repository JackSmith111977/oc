# Illustration Question Bank

Each option should explain the visible consequence, not only a mood label.

## I1 Deliverable
- 用途：主视觉 / 壁纸 / 封面 / 直播缩略图 / 连续组图 / 其他
- 画幅：16:9 横向 / 3:2 横向 / 4:3 横向 / 4:5 竖向 / 自定义
- 裁切：环境全景 / 全身 / 膝上 / 半身 / 头像

## I2 Narrative
- 瞬间类型：等待 / 发现 / 决定 / 行动中 / 行动后余韵 / 日常互动
- 情绪证据：眼神 / 嘴角 / 呼吸 / 肩背 / 手部 / 与道具关系

## I3 Acting
- 视线：直视观者 / 看向目标 / 低垂 / 越肩 / 闭眼
- 动作强度：静止克制 / 微动作 / 明确动作 / 高动态
- 外观状态：默认强参考 / 已批准发型变体 / 已批准服装变体 / 已批准情境状态

## I4 Camera
- 景别：环境 / 全身 / 半身 / 近景
- 机位：平视 / 仰视 / 俯视 / 侧后方 / 主观视角
- 镜头感：24–35mm 空间感 / 50mm 自然 / 85mm 人像压缩 / 长焦远观
- 景深：全清晰 / 中等 / 浅景深 / 极浅仅脸部

## I5 Scene
- 空间：室内私密 / 室内公共 / 城市户外 / 自然 / 舞台 / 抽象
- 信息密度：极简 / 适中 / 丰富叙事 / 装饰密集

## I6 Light
- 光源：窗光 / 日落 / 蓝调 / 月光 / 烛光 / 霓虹 / 舞台灯
- 反差：柔和低反差 / 中等 / 戏剧高反差
- 色彩：角色色主导 / 环境色主导 / 冷暖对撞 / 单色调
