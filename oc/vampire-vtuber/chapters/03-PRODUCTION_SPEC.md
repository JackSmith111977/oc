# 03 — Production Spec

## 生产顺序

1. 中立全身视觉锚点
2. 单色线稿
3. 严格正面／90°侧面／背面三视图
4. 彩色角色模型表
5. 表情与状态对照表
6. 动作与姿态对照表
7. 服装／家徽／鞋袜／眼镜／材质拆解表
8. 单人夜晚古老宅邸贵族直播最终插画

## 版式规则

- 单角色全身锚点、线稿、彩色模型表、表情表和动作表默认3:4纵向白底。
- 三视图与信息密度高的拆解表优先横向宽画布；若必须使用纵向画布，则分区排列或分图生成后按相同缩放、基线和间距合成。
- 三视图必须是严格正面、严格90°侧面、严格背面；等比例、等间距、同一基线，不使用透视或三分之四角度。
- 设定图阶段不生成文字、标签、字幕、水印或不可读标注，留白供后期手工标注。

## 渲染规则

设定图使用清爽日系动画角色设定图：干净线条、平涂为主、少量中性阴影或材质色块。线稿禁止灰色填充、排线、厚涂、戏剧化光影和复杂背景。最终插画可以使用生活系半厚涂、午间自然窗光或电影式浅景深，但必须原样保留一致性锁。
