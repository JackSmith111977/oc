# Architecture

- `SKILL.md` routes behavior and states non-negotiable invariants.
- `references/` owns policy and decision guidance.
- `schemas/` owns machine contracts.
- `scripts/` owns deterministic persistence, rendering and release checks.
- `templates/` owns data-driven publication presets.
- `examples/` are non-authoritative demonstrations.

A concept has one authoritative owner. Human-readable chapters are projections of `canon/canon.json`, never parallel fact stores.
