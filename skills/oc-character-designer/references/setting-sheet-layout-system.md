# Landscape layout system

Default digital ratio is 16:9; use 3:2 for dense turnarounds and 4:3 when print compatibility matters. Portrait pages should not exceed 4:5 unless the deliverable explicitly requires it. Split content rather than making a very tall page.

Use a stable header, page code, revision, generous gutters, one primary visual zone and compact callout zones. Keep production views orthographic and reserve perspective for acting/action pages.
