# Character-bible content design

A setting collection is an ordered set of purpose-built landscape pages, not one crowded collage.

## Core pages

1. Cover and identity
2. Master overview
3. Body core with height and proportion
4. Head construction and strict profile
5. Facial-feature breakdown
6. Hair/costume strong references
7. Full orthographic turnaround
8. Consistency lock and common errors

Standard/full presets add silhouette blocks, measurements, expression stability, hands/feet, permanent detail callouts, approved variants and revision history.

Image generation produces clean art assets. PDF/vector composition owns long text, callouts, measurements, page numbers, revision metadata and multilingual editions.
